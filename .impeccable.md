# CloudNav Design Context

## Product

CloudNav is a desktop-first personal information workspace for saved websites, RSS reading, inspiration capture, read-later triage, GitHub tracking, and focused workbench actions.

## Audience and use context

One frequent desktop user who values fast scanning, readable Chinese content, direct actions, and low-friction capture. The primary viewport is 1440px–1920px wide.

## Design direction

- Flat editorial productivity desk with continuous canvas and clear list hierarchy.
- Warm off-white surface, deep ink text, teal primary, orange only for high-attention actions.
- Use Lucide SVG icons and semantic labels.
- Use system font fallbacks first so first paint does not wait for remote fonts.
- Motion is subtle: 150–200ms color/opacity transitions only; respect reduced motion.

## Never introduce

- No gradients, glassmorphism, nested giant cards, double shadows, floating decorative blobs, or mobile-first card grids.
- No low-contrast gray body text, clipped labels, content hidden below sticky controls, or icon-only controls without accessible names.

## Product priorities

1. Readability and scan speed.
2. Reliable RSS loading, editing, refreshing, and article reading.
3. Exact deep links from unified search.
4. Fast capture and visible todo handling.
5. Consistent desktop shell across every page.
