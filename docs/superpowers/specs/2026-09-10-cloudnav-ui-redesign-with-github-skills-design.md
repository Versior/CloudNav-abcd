# CloudNav 全页面桌面 UI 重构设计

## 目标

在不破坏现有数据、同步、RSS、AI、网站入口和阅读动作的前提下，统一 CloudNav 的桌面信息架构与视觉语言，让用户可以快速定位入口、扫读 RSS、进入文章、记录灵感和处理待办；移动端只保留可用的退化布局，不再作为主要设计约束。

## 用户已经明确的约束

- 主要使用场景是电脑端，桌面宽度 1440px 以上必须优先验证。
- 置顶网站、工作台、RSS、灵感库、稍后阅读、GitHub、收件箱、阅读台都要有一致的产品感，不能再出现两套 UI。
- 不要嵌套大内框、不要大片空白、不要双重阴影、不要渐变玻璃效果、不要高级炫技动效。
- 文字要清晰显眼；正文和摘要不能用灰色压在灰色背景上。
- 现有功能和用户数据不能因为视觉重构丢失。

## 视觉系统

设计系统来源于已安装的 `ui-ux-pro-max-github`，项目主规范位于 `design-system/cloudnav/MASTER.md`。

- 风格：Flat Design + editorial productivity desk。
- 背景：暖白/浅青灰的连续画布，不再给每个区域套一层白色大卡片。
- 文字：`#17211F` 为主文字，`#425654` 为次文字，`#667A76` 只用于辅助信息。
- 主色：青绿色用于导航状态、焦点、阅读进度和确认动作。
- 强调色：橙色只用于新增、重要待处理和需要用户注意的状态。
- 错误色：深红，并配合文字说明，不能只用颜色表达。
- 边界：细线分组，避免阴影承担层级；浮层只在真的悬浮时使用一层轻微阴影。
- 字体：优先本地系统字体栈 `Inter, "Noto Sans SC", "Microsoft YaHei", sans-serif`，避免首屏等待外部字体。
- 动效：颜色、透明度和边框在 150–200ms 内变化；尊重 `prefers-reduced-motion`。
- 控件：所有按钮有可见 hover/focus/disabled 状态；图标按钮有 `aria-label`。

## 页面布局

### 应用壳层

应用固定为桌面三段语义：左侧导航、顶部命令栏、主内容区。左侧导航只负责切换视图和分类，不再重复显示同一批入口。顶部命令栏保留站内/站外搜索、天气、主题、登录和添加动作；天气在进入网站后自动刷新，但失败时只显示可读错误。

### 工作台

采用“活动时间线 + 今日处理 + 快捷入口”的编辑台结构。统计采用横向轻量指标行，分类目录采用可折叠目录条，最近访问采用时间线行，待办作为可见的浮动工作区而不是藏在页面底部的空卡片。

### 置顶网站/完整网站库

置顶网站页面只显示置顶入口；完整网站库作为独立目录视图。网站项改为列表/表格语义，列出入口、目录、访问、操作，保留详情、编辑、删除、排序、稍后阅读和打开动作。取消重复的左侧分类框与主内容中的二次目录外框。

### RSS 资讯

采用来源抽屉、文章流、阅读面板的三层关系。来源抽屉可编辑、刷新、删除订阅；文章流显示标题、来源、时间、未读/收藏状态和摘要；阅读面板显示原文入口、AI 总结、收藏、稍后阅读、记入灵感和保存入口。移动端才退化为来源/文章/阅读三步切换，桌面端默认三列连续阅读。

### 灵感库、稍后阅读、GitHub、收件箱、阅读台

统一使用“筛选栏 + 可读列表 + 详情面板”的模式。列表项保持稳定高度和清晰元信息，详情面板使用同一套标题、操作栏、AI 摘要和来源区。不要为每个页面再创造独立的卡片风格。

## 组件边界

- `App.tsx` 只负责路由、数据和全局命令；不新增页面级视觉规则。
- `index.css` 保留兼容旧组件的基础样式；新增 `styles/cloudnav-redesign.css` 作为统一视觉层，按组件语义覆盖旧 Tailwind/历史样式。
- 新增的设计 token、壳层、按钮、列表、空状态、浮层和阅读区域全部由 CSS token 控制。
- 页面组件只补充结构语义和缺失的 `data-*` 标记，不把颜色和尺寸重新硬编码进每个页面。

## 数据与交互保证

- 不改变 links、categories、RSS state、inspiration、read later、GitHub 和 reading workspace 的存储格式。
- 保留统一搜索的精确跳转目标，搜索结果打开正确页面和正确详情项。
- RSS 订阅支持添加、编辑、刷新、删除、导入、导出；抓取失败与无内容源都给出明确状态。
- 所有原有按钮继续可用，新增样式不能吞掉点击区域或键盘焦点。

## 验收标准

1. 1440px、1920px 桌面下，所有页面使用同一套壳层、字体、颜色和按钮系统。
2. 页面不出现嵌套大白框、双重阴影、文字压边和持续横向滚动。
3. 工作台首屏能看到活动、今日处理、快捷入口和天气状态；RSS 首屏能看到来源、文章和阅读内容。
4. 站内搜索、页面导航、添加/编辑/删除、RSS 操作、阅读动作、AI 摘要入口都能点通。
5. `npm.cmd test`、`npm.cmd run test:performance`、`npm.cmd run build`、`git diff --check` 全部通过。
6. 使用 webdesign-agency 命令包的诊断顺序完成一次本地审计：结构、可读性、可访问性、响应式和性能问题有记录；最终完成 polish 和回归验证。
