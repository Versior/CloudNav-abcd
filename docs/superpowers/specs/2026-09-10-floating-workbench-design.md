# 工作台悬浮待办设计

## 目标

保留工作台右下角悬浮待办，但让它成为可移动、可收起、可筛选的全局工具，不遮挡主要内容，也不再与工作台模块重复。

## 交互方案

悬浮待办默认吸附在右下角，保留展开状态。用户可以通过拖拽手柄移动它，松开后自动吸附到最近的左右边缘，并将位置限制在当前视口内。位置、展开状态和筛选状态保存在本地浏览器中，不写入工作台业务数据。

展开面板提供快速添加、全部/进行中/已完成筛选、完成/恢复、删除和清除已完成。列表在面板内部滚动，面板最大高度受视口限制。收起状态只显示图标和未完成数量，避免遮挡。

## 视觉方案

使用 CloudNav 当前深绿品牌色，采用轻边框、单层阴影和清晰文字层级。拖拽手柄、筛选按钮、状态数量和关闭/收起动作均提供明显的 hover、focus 和 aria 标签。面板不使用复杂动画，并尊重 prefers-reduced-motion。

## 影响范围

只修改 FloatingTodo 组件、其样式和 UI 合约测试；不修改 RSS、阅读台或工作台数据结构。业务待办仍由 WorkbenchToolsState 持久化，悬浮位置等 UI 状态使用独立 localStorage key。

## 验收标准

1. 面板仍然以悬浮方式显示。
2. 拖动后能吸附到左右边缘，刷新页面后位置保持。
3. 收起后不显示正文列表，只显示未完成数量。
4. 筛选、完成、恢复、删除和清除已完成均可用。
5. 面板内部滚动，不推动或覆盖工作台布局。
6. 现有类型检查、测试和生产构建通过。
