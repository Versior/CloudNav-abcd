# 阅读台 v2 设计说明

## 目标

把阅读台从多层工具拼接页面改成桌面优先的连续阅读工作区，让文章正文始终保持视觉中心，来源筛选、阅读队列和笔记都服务于阅读，不再制造横向滚动和嵌套卡片。

## 参考与取舍

- 借鉴 Readwise Reader 的可收起侧栏、可调正文宽度和连续阅读体验。
- 借鉴 Feedly 的来源与文章层级，但不长期展示来源横向标签。
- 借鉴 Miniflux 的低装饰、高可读性和键盘操作。
- 不采用常驻三栏。来源改为页头筛选抽屉；桌面主视图只保留阅读队列和正文两列。

## 页面结构

1. 页头：阅读台标题、未读统计、导入/导出和快捷键。
2. 阅读控制条：来源筛选按钮、Inbox/稍后阅读/已归档、搜索、保存视图。
3. 快速收集条：标题、网址、加入 Inbox，保持一行紧凑高度。
4. 主阅读区：左侧队列，右侧正文。两列各自垂直滚动，页面本身不再承担第三层滚动。
5. 来源抽屉：以纵向列表展示来源、未读数和错误状态，打开/关闭不改变正文宽度。
6. 正文：顶部固定操作条、来源和元数据、适中标题、AI 摘要、正文、笔记/高亮、阅读状态操作。

## 视觉规则

- 取消来源横向 chip 带和横向滚动条。
- 页面背景使用低对比暖灰，正文使用白色阅读画布。
- 仅使用一个青绿色强调色；选中态使用左侧色条和浅色背景，不使用双重阴影。
- 正文最大宽度 760px，标题 2.25rem 起步并允许自然换行，正文 1rem、行高 1.9。
- 操作按钮统一 36px 高度，图标按钮必须有 aria-label/title。
- 文章列表显示来源、未读态、标题、摘要、作者/网址和阅读进度，不强制显示所有操作。

## 交互规则

- 来源筛选入口为“来源”按钮，抽屉打开后点击来源立即筛选并关闭抽屉。
- 切换文章只滚动正文列到顶部，不滚动整个页面。
- 点击“沉浸阅读”隐藏队列，正文居中；再次点击恢复双列。
- 保留 j/k、l、e、s、/、? 快捷键。
- 底部笔记和高亮保持原有保存逻辑，不改数据结构。
- 在 prefers-reduced-motion 下不使用位移过渡。

## 验收标准

- 1440px 以上桌面窗口不出现横向滚动条。
- 来源、搜索、状态筛选、加入 Inbox、选中文章、笔记保存和快捷键均保持可用。
- 滚动队列不会让正文消失；滚动正文不会让队列内容被页面带走。
- RSS、网页文章、灵感笔记和 GitHub 内容继续共享同一阅读详情结构。
- 现有测试全部通过，并新增阅读台 v2 的结构契约测试。
